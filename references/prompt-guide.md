# 提示词与镜头语言手册

写分镜时查这里。核心原则一条：**写你看得见的东西**。

## 基本公式

```
主体 + 动作 + 环境光线 + 镜头运动 + 质感
```

例：

> 一只橘猫（主体）蜷在窗台的毛毯上伸懒腰（动作），午后阳光斜射进来形成百叶窗的光斑（光线），镜头缓慢横移（运镜），浅景深，胶片颗粒（质感）

五个位置都能省，但**至少要有主体和动作**，否则模型会自由发挥。

## 写得好的和写得差的

| 差 | 为什么差 | 改 |
|---|---|---|
| 一个很有氛围感的咖啡馆 | 「氛围感」不可见 | 木桌上的拿铁冒着热气，窗外是雨天的街道，暖黄吊灯，浅景深 |
| 女主角伤心地走在街上 | 情绪不可见，容易崩脸 | 女人低头快步走过湿漉漉的街道，雨水打湿头发，冷色调，镜头跟拍背影 |
| 不要有人 | 模型会理解成「有人」 | 写进 `negative` 字段 |
| 一段史诗般的旅程 | 太抽象，一镜装不下 | 拆：远山日出 → 背包客背影 → 地图特写 → 脚步踩过雪地 |
| 高科技感的产品展示 | 「高科技感」空心 | 金属质感耳机在黑色背景上缓慢旋转，蓝色轮廓光扫过，微距 |

## 镜头语言词汇表

写 `prompt` 时直接抄。

### 景别
| 词 | 效果 |
|---|---|
| 大远景 / 航拍 | 交代环境，气势 |
| 全景 | 人物全身+环境 |
| 中景 | 腰部以上，对话常用 |
| 近景 | 胸部以上，表情为主 |
| 特写 / 微距 | 细节，最有冲击力 |

### 运镜
| 词 | 效果 |
|---|---|
| 镜头缓慢推进 | 增强注意力，情绪升温 |
| 镜头缓慢拉远 | 揭示环境，收尾感 |
| 镜头横移 / 平移 | 展示空间，适合转场 |
| 镜头跟随 | 跟拍主体，代入感 |
| 手持轻微晃动 | 纪实感，紧张感 |
| 快速推近 | 冲击，强调 |
| 环绕拍摄 | 展示立体感，产品常用 |
| 向上摇到天空 | 自然的段尾 |

### 光线
| 词 | 效果 |
|---|---|
| 晨光 / 黄金时刻 | 温暖，希望 |
| 逆光 / 侧逆光 | 轮廓光，电影感 |
| 硬光 / 高对比 | 强烈，戏剧 |
| 柔光 / 漫射 | 温柔，干净 |
| 霓虹 / 冷暖对撞 | 都市，赛博 |
| 烛光 / 单一光源 | 亲密，悬疑 |

### 质感
`浅景深` `胶片颗粒` `低饱和` `高饱和` `油画质感` `3D 渲染` `定格动画` `水墨` `赛博朋克` `复古 8mm`

## 按视频类型的分镜模板

### 产品宣传（15–30s，5–6 镜）

```
s1  产品在暗背景中旋转，轮廓光扫过          5s
s2  微距特写材质纹理，光斑流动              5s
s3  使用场景：手拿起产品的动作              5s
s4  产品与人的互动，浅景深                  5s
s5  产品静置在桌面上，镜头缓慢拉远          5s
```

要点：**统一背景色和光线**，否则拼起来会跳。产品类强烈建议先出首帧图。

### 探店 / 空间（20–40s）

```
s1  门头外观，镜头横移                       5s
s2  推门进入，视角穿过门框                   5s
s3  吧台特写，咖啡师操作                     5s
s4  食物/饮品微距，蒸汽或水珠                5s
s5  客人交谈的中景，暖光                     5s
s6  空镜收尾：桌面、窗景、招牌               5s
```

要点：**保持同一空间的光线色温**。写进 `style`：「暖色调，室内自然光，木质质感」。

### 人物口播（15–30s）

```
s1  人物中景正面，室内柔光，轻微呼吸起伏     5s
s2  人物侧脸特写，眼神看向镜头外             5s
s3  手部动作细节（翻书/敲键盘）              5s
```

要点：人物一致性最难。**必须**先出首帧图再图生视频，且每张首帧图用同一段人物描述。

### 情绪短片 / 风景（15–30s）

```
s1  大远景，天空与地景                       5s
s2  中景，主体入画                           5s
s3  特写，细节情绪                           5s
s4  空镜，留白收尾                           5s
```

要点：这类最吃 `style`，把调色倾向写清楚。运镜统一用「缓慢」，快切会破坏情绪。

## 首帧图的提示词怎么写

图生视频的首帧图决定了整镜的构图和角色，值得多花点力气。

首帧图提示词 = **视频 prompt 去掉运镜 + 加上静态构图词**：

```
视频: 咖啡师在吧台后制作手冲，水柱注入滤杯，蒸汽升起，镜头缓慢推进
首帧: 咖啡师在吧台后制作手冲，水柱注入滤杯，蒸汽升起，中景构图，暖光，浅景深
```

多镜要保持一致时，把不变的部分抽出来固定在每张图里：

```
[固定的角色/场景描述] + [这一镜的具体动作] + [构图词]
```

例：固定「短发的年轻女性，米色针织衫，木质厨房」，只改每镜动作。

## 中文还是英文

| provider | 建议 |
|---|---|
| ark / kling / minimax / vidu | 中文，对中文语义理解更好 |
| runway / veo / luma | 英文，中文会有语义损耗 |

脚本不自动翻译。如果用户是中文需求但要跑 veo，Agent 应该先把 prompt 译成英文再写进分镜，或者干脆选国内模型。

## negative 字段怎么写

只写**明确不该出现的物体或画面缺陷**，逗号分隔：

```
文字, 水印, logo, 畸形手指, 多只手, 面部扭曲, 模糊, 低分辨率, 过曝
```

不要写抽象概念（「不要难看」这种无效）。也不要写「不要有人」——容易反向触发，直接换成不受人物干扰的构图描述更稳。

## 长 prompt 还是短 prompt

- **ark / kling**：50–150 字最佳，能读懂较复杂的场景描述
- **minimax / vidu**：30–80 字，太长容易丢细节
- **runway / veo**：英文 30–80 词，结构清晰的短句比长句好
- **luma**：短句为主，它偏好诗意的简洁描述

超过 200 字基本都是浪费，把细节拆到别的镜头去。
